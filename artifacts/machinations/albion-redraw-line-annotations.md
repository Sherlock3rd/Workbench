# Albion 讨论重绘图局部修改清单

## 当前规则

- `讨论重绘图` 以最新原图为底，不再全局重排。
- 未列为问题的节点、连线、坐标和布局禁止修改。
- 本文只记录相对原图发生变化的节点和连线。

## 节点修改

- `2701`：从 `交易行成交` 改为 `交易行成交出库`。
  - 类型保持 `Gate`。
  - 坐标、宽高保持原图不变。
  - 含义：强调这里是交易行库存装备的出库触发，不创造玩家总银币。

- `678`：从 `装备持有/使用` 改为 `玩家装备持有/使用`。
  - 类型保持 `Pool`。
  - 坐标、宽高保持原图不变。
  - 含义：买家成交后拿到装备，后续再进入 PvP 战斗使用。

- `redraw_silver_fast_travel`：新增 `快速旅行/传送费`。
  - 类型：`Drain`。
  - 含义：潜在遗漏的银币出口。

- `redraw_silver_island`：新增 `岛屿/建筑维护`。
  - 类型：`Drain`。
  - 含义：潜在遗漏的银币出口。

- `redraw_silver_respec`：新增 `自动专精/声望转化`。
  - 类型：`Drain`。
  - 含义：潜在遗漏的银币出口。

- `redraw_market_buy_demand`：新增 `玩家买单/购买需求`。
  - 类型：`Register`。
  - 公式：`银币购买力 + 装备需求`
  - 含义：补回新版原图里缺失的需求侧触发，避免交易行成交只由库存自动推出。

- `redraw_consumable_sink`：新增 `消耗品使用消耗`。
  - 类型：`Drain`。
  - 含义：复用新版原图已有消耗品制造/库存/交易行链路，只额外补一个主要使用消耗出口。

## 连线修改

- `2702`：`交易行成交出库 -> 玩家装备持有/使用`。
  - 类型：`Resource`
  - 备注：`买家获得装备`
  - 数值：`1`
  - 原因：成交后装备进入买家持有/使用池，再由玩家选择 PvP、PvE 或继续交易。

- `1170`：保持 `玩家市场银币池 -> T4订单创建费+成交税`。
  - 类型：`Resource`
  - 备注：`扣除规费`
  - 数值：`300`
  - 资源：`银币`
  - 原因：费用是银币 sink，应从玩家银币池流向 Drain。

- `1171`：保持 `玩家市场银币池 -> T6订单创建费+成交税`。
  - 类型：`Resource`
  - 备注：`扣除成交税`
  - 数值：`500`
  - 资源：`银币`
  - 原因：成交税是银币 sink，应从玩家银币池流向 Drain。

## 新增局部连线

说明：原图已经包含金币充值、银币买金币、金币卖银币、月卡和外观链路，本轮不再新增第二套 `redraw_gold_*` 金币模块。

- `redraw_silver_to_market_buy_demand`：`玩家市场银币池 -> 玩家买单/购买需求`。
  - 类型：`State`
  - 备注：`购买力形成买单`
  - 数值：`1`
  - 原因：玩家市场银币池只作为购买力信号，不用 Resource 线从总银币池抽走银币。

- `redraw_market_buy_demand_to_match`：`玩家买单/购买需求 -> 交易行成交出库`。
  - 类型：`State`
  - 备注：`买单触发成交`
  - 数值：`1`
  - 原因：成交需要库存和需求共同成立，避免读成“只要有库存就自动出库”。

- `redraw_silver_fast_travel`：`玩家市场银币池 -> 快速旅行/传送费`。
  - 类型：`Resource`
  - 备注：`快速旅行/传送费`
  - 数值：`200`

- `redraw_silver_island`：`玩家市场银币池 -> 岛屿/建筑维护`。
  - 类型：`Resource`
  - 备注：`岛屿/建筑维护`
  - 数值：`500`

- `redraw_silver_respec`：`玩家市场银币池 -> 自动专精/声望转化`。
  - 类型：`Resource`
  - 备注：`自动专精/声望转化`
  - 数值：`1000`

- `5485`：`消耗品库存 -> 消耗品流向`。
  - 类型：`Resource`
  - 备注：`剩余进入市场/黑市流向`
  - 数值：`20%`
  - 原因：新版原图已有 `消耗品库存 -> 消耗品流向 -> 消耗品交易行库存/黑市收购`，这里只把流向比例改成未使用或可交易的剩余部分。

- `redraw_consumable_use_drain`：`消耗品库存 -> 消耗品使用消耗`。
  - 类型：`Resource`
  - 备注：`大部分用后消耗`
  - 数值：`80%`
  - 原因：表达食物/药水大部分随 PvP、PvE、采集使用后永久消失。

- `redraw_pvp_consumable_demand`：`PvP 战斗使用 -> 消耗品使用消耗`。
  - 类型：`State`
  - 备注：`战斗消耗需求`
  - 数值：`1`

- `redraw_pve_consumable_demand`：`PvE 刷取玩家 -> 消耗品使用消耗`。
  - 类型：`State`
  - 备注：`刷取消耗需求`
  - 数值：`1`

- `redraw_gather_consumable_demand`：`采集者 -> 消耗品使用消耗`。
  - 类型：`State`
  - 备注：`采集增益需求`
  - 数值：`1`

## 保持不变的关键原图结构

- 采集、等级分流、三档原料库存、三档精炼、三档制造和三档装备库存保持原图布局。
- 黑市三档收购、收购流向、销毁终点、`PvE掉落库`、`PvE掉落分拣` 保持原图布局。
- PvP 战斗使用、死亡判定、装备掉落和装备破坏保持原图布局。
- 市场商人、低价倒卖库存、市场价差、跨城运输风险，以及新版原图已有的消耗品制造/交易模块保持原图布局；只新增买单需求、银币出口检查和消耗品使用消耗出口。
