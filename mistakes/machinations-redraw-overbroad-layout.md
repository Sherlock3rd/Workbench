# Machinations 讨论重绘误做成全局重排

## 问题
- 用户要求讨论重绘图用于辅助修改原图，但实际生成时一度另起一套完整布局。
- 这破坏了用户在 Machinations 中已经画好的正确部分，导致“讨论重绘图”不再能对应原图逐点修正。

## 原因
- 混淆了两种视图目的：
  - `原坐标复原图`：校验抓取数据。
  - `讨论重绘图`：应基于原图局部修正问题节点。
- 误把讨论重绘图当成“最佳实践整理图”，擅自重排和改写了大量无问题节点。

## 修复
- `讨论重绘图` 改为复制最新原图全部节点和连线。
- 只允许修改明确列为问题的节点和连线。
- 当前局部修改：
  - 节点 `1148`：`成交撮合` -> `交易行成交出库`。
  - 节点 `678`：`装备使用` -> `玩家装备持有/使用`。
  - 连线 `1164`：改为 `交易行成交出库 -> 玩家装备持有/使用`。
  - 连线 `1170`、`1171`：费用方向改为从玩家银币池流向 Drain。

## 预防
- 以后只要用户已经在 Machinations 原图中手工画过内容，讨论图必须以原图为底。
- 未被明确判定为问题的节点，不得改坐标、改类型、改标签或改连线。
- 测试必须约束：重绘图节点数等于原图，非问题节点坐标和标签保持一致。
